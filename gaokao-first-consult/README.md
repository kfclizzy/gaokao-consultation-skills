# 高考初访准备与咨询支持

读取学生与家长材料，形成统一顺序提问表、理论选择依据及政策资料链接。

这是 Agent Skill 指令包，不是独立软件，也不附带实时招生数据库。完整执行需要支持技能的助手、联网检索、文件读写以及生成HTML和Excel的能力。不同工具兼容性需实际确认。

## 安装与使用

下载仓库并解压，将 `gaokao-first-consult` 完整文件夹放入所用工具的技能目录；必须保留 SKILL.md、agents 及已有 references。具体导入位置按工具说明操作。已有同名版本请先备份。

示例（请替换省份、年份、日期与输出位置）：

> 使用 $gaokao-first-consult，依据我提供的匿名学生与家长信息表准备初访。报考省份为上海，招生年份2027，咨询日期2026年11月5日。形成一张顺序提问表，并将政策HTML手册和Excel节点表链接到初访方案。输出到我指定的案例目录。

初访技能可独立使用，也可与 gaokao-policy-library 配套。政策技能可单独维护公共资料。两者不会自动定时运行。

## 输出与边界

读取学生与家长材料，形成统一顺序提问表、理论选择依据及政策资料链接。 初访内部判断与家庭可读政策手册分开保存。未公布、无法核实或离线未复核的信息需明确标记；不提供确定录取承诺。示例是使用输入，不是已完成的演示结果。
