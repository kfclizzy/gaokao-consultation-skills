# 工具表与输出结构

## 信息采集表
字段｜学生填写｜家长填写｜来源页码｜状态｜需补充的问题。
至少含：咨询日期、招生年份、报考省份、考生类别与资格、年级、选科、各次成绩及日期/满分/原始或赋分/排名、合格考、春考及外语考试、报名状态、健康及正式体检、地域、专业/院校偏好、预算、升学与就业期待、资源及学生知情程度。

## 场景分流（准备判断，不另建现场问题清单）
场景｜证据｜优先任务。可同时存在方向探索、意向理解不足、亲子偏好差异、资料矛盾、成绩资格未明、时间紧迫。无证据不贴冲突或心理标签。

## 唯一的初访顺序提问表
资料对照是准备依据，所有现场问题只呈现在一张表中，禁止另起“重点澄清”“必问清单”重复输出。

列：顺序/议题｜问谁及资料依据｜主问与条件追问｜目的/理论视角及回答后的分支｜现场记录。
顺序：①咨询目标，②信息表已有内容澄清，③未覆盖或需深化。已在②问透的主题不在③重复。时间敏感事项可以确认目标后提前核查，说明原因。

检查遗漏：咨询目标与担忧；成绩口径与变化；当下报名确认缴费；合格考；本科/专科、公办/民办接受度；学费和年度总预算；学生自己的地域底线；专业学校地域费用取舍；专业理解及经历；学习支持；家庭决策和配合。
条件追问：艺体资格、特殊身份、港澳境外、身体限制、复读、专科后升学等。已填信息深化其含义，不机械重问；未来事件不作为遗漏。后续升学不得保证政策不变或必定成功。

理论使用参见career-theories.md。政策、费用、成绩核验可标事实工作，不必每一行都配理论。普通表达提问，内部标注理论。

## 政策核验表
路径｜解释层级｜资格与缺口｜成绩/选科/学考｜报名/校测节点｜当前报名状态｜录取及兼报限制｜费用学制｜官方原文及发布日期｜核验日期｜下一步责任人。
标注历史回看信息。未发布的日期不以惯例写成确定日程。

## 推荐前检查表
- 报考省份、招生年份和咨询时间是否确认？
- 早期模拟考、春考450口径、秋考本科/专科口径是否混用？
- 意向是学生本人选择还是家长推测？
- 路径的身份、报名、学考、选科、体检和费用是否核实？
- 春考、专科自招及秋考的互斥触发是否查到当年条文？
- 是否把爱好错当报考资格，或把家庭资源当成就业保证？
- 是否保留适用路径、暂不适用原因和待公布事项？

## 会谈建议结构
可按60—90分钟调整，并先确认实际时长：开场与目标；学生先讲、家长补充；澄清差异和资料；结合孩子情况解释路径；用复述检验双方理解；约定资料、任务和复核时间。政策紧迫时调整顺序。

## 最终初访文档顺序
1. 已确认的咨询背景及资料摘要。
2. 场景判断、主理论及必要辅助视角的选择依据。
3. 一张初访顺序提问表：目标 → 原表澄清 → 遗漏与深化；理论目的和条件追问写在同表。
4. 个案化记录：事实、假设、问题编号、实际回应和修正；会前回应留空。
5. 政策讲解环节：独立HTML手册链接、版本、本案重点、Excel附件链接，不插入整篇长文。
6. 初访结束的理解确认、待收资料和待商议行动。

文件放置：同一案例文件夹内保留初访准备.md、初访准备.html、本省年度政策手册.html、政策与节点.xlsx。名称可沿用用户现有文件，不强制改名。HTML主方案标为内部使用，家庭手册不携带内部假设。

## 留给后续 Skill 的交接
案例代号、资料日期、咨询目标、已确认事实、未决问题、政策来源、路径状态、待验证假设、理论选择理由、对应问题编号、实际回应与理解修正（会前留空）、行动责任人及期限。这里只预留结构，不虚构咨询结果，不自动发送或对外建档。
