# 初访生涯理论：选择、提问与个案化

本文件为基于公开原始研究及专业机构资料的工作性归纳，不是标准测评或治疗手册。下列问题为本工作台拟写，非原版量表题目。理论帮助组织假设和提问，不证明个体结论。

## 选择规则
先看案例中的事实、来访目标及资料缺口，再选理论。不要求每次全部使用；通常选择一个组织流程的主框架，加一到两个确有证据支持的辅助视角。可以不选某理论，注明理由。现场出现不同证据时修正选择。
每个选用视角记录：事实出处 → 暂定理解 → 为什么选 → 对应问题 → 什么回答支持/修正理解 → 现场回应（待填） → 后续行动。政策、成绩口径和费用核验属于事实工作，不强行包装成理论技术。

## 1. CIP认知信息加工与CASVE决策循环
核心：区分自我知识、选项知识、决策技能与对自己决策的想法。CASVE为觉察需要选择（Communication）、分析、综合、价值权衡、执行的循环，不必在初访完成整轮。
适用：不知道自己缺什么、专业与政策信息少、选择混乱、难以比较。初访可重点建立问题定义、区分知识缺口，约定小型信息探索任务。
问题：“这次到底要做什么决定？”“你知道哪些、哪些只是听说？”“哪些选择条件最重要？”“先补哪一项信息才有助于比较？”
边界：资料不全不等于认知缺陷；不由一次成绩推断决策能力，不自制CTI分数。
来源：FSU理论研究与实践资源 https://career.fsu.edu/tech-center/resources/cognitive-information-processing ；实际决策辅导说明 https://career.fsu.edu/students/career/planning/decision-making 。

## 2. SCCT社会认知生涯理论
核心：学习经历、自我效能（对具体任务能否完成的信念）、结果预期、目标以及支持/障碍共同影响兴趣和选择。自我效能不等于自尊或客观能力。
适用：因受挫放弃方向、对高薪稳定等结果期待突出、家庭资源/现实障碍影响选择。分开问“想做吗”“觉得做得到吗”“预计做了会怎样”。
问题：“说自己擅长数学，有什么经历？”“不喜欢化学是内容、困难、体验还是其他原因？”“为什么认为财经能带来你期待的生活？”“家里的资源具体能帮你试做什么？”
边界：模拟考低分不证明低自我效能；家庭有资源不证明可保证成功；既不能只鼓励，也不能忽略实际资格和结构性限制。
来源：Lent、Brown、Hackett（1994）原始研究，DOI https://doi.org/10.1006/jvbe.1994.1027 ，作者上传全文 https://www.researchgate.net/publication/230557657_Toward_a_Unifying_Social_Cognitive_Theory_of_Career_and_Academic_Interest_Choice_and_Performance ；Brown与Lent（1996）咨询应用 https://doi.org/10.1002/j.2161-0045.1996.tb00451.x 。

## 3. Super生涯发展／生涯彩虹（生涯—生活空间）
核心：生涯是发展过程，涉及自我概念及家庭、学生、休闲、工作等多重角色。青少年通常处于探索任务中，但不以年龄机械判定成熟程度。
适用：把专业选择等同一生职业、学生与子女角色期待拉扯、兴趣与未来生活想象不清。
问题：“你希望大学生活和未来生活是什么样？”“作为学生和子女，你分别觉得有哪些期待？”“这些期待中哪些属于你，哪些还想商量？”
边界：不把家长参与自动视为冲突或不独立；不由年级宣称生涯发展迟滞；生涯彩虹是表达工具，不自制成熟度评分。
来源：NCDA专业文章（含Super原始著作引用，属于专业机构二级解释） https://www.ncda.org/aws/NCDA/pt/sd/news_article/559383/_PARENT/CC_layout_details/false 。

## 4. Holland RIASEC兴趣与环境匹配
核心：从实际活动探索现实型、研究型、艺术型、社会型、企业型、常规型六类职业兴趣；兴趣不同于能力、价值观、成绩及资格。
适用：只勾了财经、理工、艺术等宽泛标签，难以表达喜欢什么；可用活动经历深化，不必首次就做正式测评。
问题：“财经吸引你的是分析数据、组织说服、规则整理还是其他？”“做音乐、运动时，喜欢创作、练习、表演还是组织活动？”追问实际例子，不强迫套六类。
边界：无正式工具和有效数据不输出三字码或匹配百分比；有音乐爱好不证明适合艺考；美国职业映射不直接等同中国专业招生适配。正式测评另查适用人群、中文版本证据及许可。
来源：O*NET Interest Profiler官方技术手册说明 https://www.onetcenter.org/reports/IP_Manual.html 及工具 https://www.onetcenter.org/IP.html 。

## 用于后续个案报告
会前只写“拟采用”“待验证假设”。会后依据实际记录填写：选择该视角的案例事实、实际问了什么、来访者如何回应、理解如何变化、采取何种行动及局限。没有实施的技术和未得到的结果不能写成已完成。内部假设不直接变成来访者报告结论。
