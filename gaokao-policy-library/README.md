# 高考政策资料维护

按省份与招生年份核验官方政策，增量维护可复用政策库，交付HTML手册、Markdown源稿和Excel节点表。

这是 Agent Skill 指令包，不是独立软件，也不附带实时招生数据库。完整执行需要支持技能的助手、联网检索、文件读写以及生成HTML和Excel的能力。不同工具兼容性需实际确认。

## 安装与使用

下载仓库并解压，将 `gaokao-policy-library` 完整文件夹放入所用工具的技能目录；必须保留 SKILL.md、agents 及已有 references。具体导入位置按工具说明操作。已有同名版本请先备份。

示例（请替换省份、年份、日期与输出位置）：

> 使用 $gaokao-policy-library，维护上海2027届政策库，适用日期2026年11月5日。先检查已有资料，再补查变化及缺项，生成HTML手册、Markdown源稿及可编辑Excel节点表，标明来源、年份与核验状态。

初访技能可独立使用，也可与 gaokao-policy-library 配套。政策技能可单独维护公共资料。两者不会自动定时运行。

## 输出与边界

按省份与招生年份核验官方政策，增量维护可复用政策库，交付HTML手册、Markdown源稿和Excel节点表。 初访内部判断与家庭可读政策手册分开保存。未公布、无法核实或离线未复核的信息需明确标记；不提供确定录取承诺。示例是使用输入，不是已完成的演示结果。
